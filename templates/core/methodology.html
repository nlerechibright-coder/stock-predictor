Model Methodology & Architecture

A technical overview of how the StockPredictor system generates forecasts.

1. Data Acquisition & Preprocessing

The system utilizes the yfinance library to fetch daily historical market data for Apple Inc. (AAPL) from NASDAQ. The dataset includes Open, High, Low, Close, and Volume metrics spanning over 5 years.

  • Cleaning: Missing values and duplicate timestamps are removed.
  • Chronological Sorting: Data is strictly ordered by date to prevent temporal data leakage.

2. Feature Engineering

Raw market data is transformed into technical indicators that help the machine learning model identify trends and volatility:

Moving Averages (MA_7, MA_30)

Smooths price data to identify trend directions.

Daily Returns & Volatility

Captures the percentage change and risk profile of the stock.

Lagged Features (Lag_1 to Lag_3)

Previous days' closing prices used as autoregressive inputs.

Standard Scaling

Normalizes all features to have a mean of 0 and variance of 1.

3. Machine Learning Model

The system employs an XGBoost Regressor (Extreme Gradient Boosting). XGBoost was chosen over traditional statistical models (like ARIMA) because it excels at capturing non-linear relationships in tabular financial data.

  • Training Strategy: 80/20 chronological split (no random shuffling) to simulate real-world forecasting.
  • Evaluation Metrics: Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and Directional Accuracy.
  • Inference: The model performs autoregressive forecasting, predicting Day 1, appending it to the dataset, and using it to predict Day 2, and so on.

⚠️ Academic Disclaimer: This system is designed for educational and demonstrative purposes. Financial markets are influenced by unpredictable real-world events. The predictions generated by this model are statistical estimates based on historical patterns and should not be construed as financial or investment advice.
